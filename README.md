# 공사기간 적정성 검토 에이전트

「적정 공사기간 확보를 위한 가이드라인(2026, 국토교통부)」과 「공공 건설공사의 공사기간 산정기준(국토교통부 고시 제2024-1021호)」에 따라
공사기간을 산정하고 적정성을 검토하여 **보고서 · 보고서 부록 · 주공정(Critical Path) 공정표**를 작성합니다.

- **에이전트**: `.claude/agents/construction-period-reviewer.md` (Claude Code 서브에이전트)
- **스킬**: `/construction-period-review`
- **계산 엔진**: `cpa/` (Python) — 검토엑셀의 ①→⑦ 순서로 처리

## 처리 흐름

| 단계 | 내용 | 가이드라인 |
|---|---|---|
| ① 공사개요 | 사업정보, 착공일, 준비·정리기간, 목표기간 | 제2장 2.(2)·(5) |
| ② 비작업일수 | **관측지점(95개) 선택 + 공정별 기상프로필(기상조건·적용률 선택)**, A+B−C, 주40시간 하한 8일 | 제2장 2.(3), 부록1·2·3 |
| ③ 1일작업량 | 수량 ↔ 부록4 DB 매칭(수동 > DB지정 > 자동), **현장여건·공사규모·지질·기상기후 보정계수** | 제2장 2.(4), 부록4 |
| ④ 작업일수 | ROUNDUP(수량 ÷ (1일작업량 × 보정 × 작업조)) | 제2장 3.(2) |
| ⑤ 주공정 | **토목·건축·기계·전기·시운전** 공정 CPM(FS/SS/FF), 공종별 공사기간 = 작업일수 + 비작업일수 | 제2장 3.(3)·(4) |
| ⑤-1 공기조정 | 목표기간(발주처 요구 또는 **건설사업관리기간**) 초과 시 **작업조 증원 + 동시수행 공정 중첩** | — |
| ⑥ 종합 | 공사기간 = 준비 + 비작업 + 작업 + 정리 (+보정) | 제2장 1. |
| ⑦ 적정성 | **부록5 산정공식 / 최근 5년 동종공사 평균** + 준비·정리, ±20% 판정 (건설사업관리기간·환경공단 기준 참고) | 제3장 2.(3), 부록5 |
| 추가검토 | 동절기 공사중지 반영 시 일정 | — |

## 웹 화면에서 실행 (권장) — 공정 선택 · 수량파일 첨부 방식

| 단계 | 내용 |
|---|---|
| ① 파일 추가 | **1.1 공정 선택**: 처리시설공사(처리시설공사·구내배관공사) / 관로공사(관공사·배수설비 공사·펌프장 공사)<br>**1.2 공정별 수량파일 첨부**: 토공·구조물공·가시설공·포장공·부대공·관로공·기타 등 여러 엑셀(설계내역서·수량집계표). 시트별 머리글(공종·규격·단위·수량) 자동 탐지, 파일명으로 공종 분류(변경 가능) |
| ② 검토 실행 | **2.1 공사개요**: 사업명·공사명·공사비·착수/준공예정일·시설구분·발주청·지역<br>**2.2 비작업조건**: 지역→관측지점 자동선택(변경 가능), 공정 유형별 기상조건·적용률, 미세먼지, 동절기, 월별 비작업일수 미리보기<br>**2.3 작업일수 산정**: 수량 ↔ 부록4 1일작업량 자동매칭(행별 DB지정·수동입력·작업조·포함 여부 수정), 순작업일수 + **간접작업일수**(검측·양생·장비조립 자동) + **보정일수**(도심지·소규모·지지력시험), 공정 자동 구성(선행관계·중첩률)<br>**2.4 공사기간 검토**: CPM 산정, 공사개요 공사기간(준공예정일) 초과 시 **작업조 증원·공정 중첩** 자동 조정<br>**2.5 유사사례·적정성**: 유사사례 입력, 유사공정(부록5 산정공식·환경공단 산정식·경험치) 선택, ±20% 비교검토<br>**2.6 CP 공정 검토**: 주공정·공정표·CPM 계산표 |
| ③ 결과 확인 | 공사기간 적정성 평가(기준별 편차·판정), 공사기간 구성, 주공정, 월별 비작업일수 |
| ④ 보고서 작성 | **보고서(HWPX, 한글)**, 부록(엑셀, 부록1~11 시트), 주공정 공정표(엑셀·PDF), 검토과정 워크북 |
| ⑤ 보고서 출력 | 미리보기(PDF·HWPX 본문), PDF 변환, 파일별·전체 ZIP |

- 왼쪽 [예제로 시작]을 누르면 `examples/수량첨부_예제/`(대죽 수량 + 가상 관로 수량)가 첨부된 작업이 만들어집니다.
- 입력서식(1_공사개요~5_유사사례)·기존 검토엑셀을 직접 올리는 이전 방식은 상단 링크(`/classic`)에서 사용합니다(단일·복합공사).
- 1일작업량을 매칭하지 못한 수량행은 작업일수에 반영되지 않으며 2.3 화면과 `검토입력.xlsx`의 `6_제외수량` 시트에 사유와 함께 남습니다. DB 번호 지정 또는 수동 1일작업량 입력으로 반영하십시오.
- HWPX는 python-hwpx로 작성(OWPML 구조 검증)합니다. PDF·미리보기는 같은 내용의 문서를 LibreOffice로 변환한 것입니다.

```bash
# Windows: run_web.bat 더블클릭   /  macOS·Linux: ./run_web.sh
python3 -m cpa web --open               # → http://127.0.0.1:8000 (서버 준비 후 브라우저 자동 실행)
# 사내 서버(여러 사용자): docker build -t cpa-web . && docker run -p 8000:8000 -v cpa-data:/data cpa-web
```
- PDF 변환에는 LibreOffice가 필요합니다(없으면 DOCX로 제공). Docker 이미지는 LibreOffice·나눔글꼴을 포함합니다.
- 작업 데이터는 `web_data/`(또는 `CPA_WEB_DATA`)에 작업별로 저장됩니다.

### 복합공사(여러 공사 동시 시행)
- 공사별 입력서식을 각각 작성(각자의 1_공사개요·3_수량·4_공정·5_유사사례)하여 공사별로 첨부합니다.
- 통합 검토: 공정ID에 공사코드(A-, B-…)를 붙여 하나의 공정망으로 합치고, 후속 공사는 착공일(착수가능일) 이후 착수합니다. 준비기간은 최초 착공 공사에 1회(공사별 '준비기간 별도' 선택 가능), 정리기간은 최종 준공 시 1회 계상합니다.
- 공사별 검토: 각 공사 입력서식으로 독립 산정하여 공사별 적정성(부록5·동종실적 ±20%)을 판정합니다(검토엑셀 ⑦ 방식).
- 성과품: 통합 보고서(공사별 적정성 표 포함) + `공사별/<공사명>/` 공사별 보고서·부록·공정표·워크북.
- 웹 ② 화면에서 공사별 파일 교체·착공일 변경·공사 추가/삭제가 가능하며, 공통 조건(관측지점·동절기·보정계수·목표기간 등)은 모든 공사에 일괄 적용됩니다.

```bash
python3 -m cpa composite "횡산소규모=a.xlsx" "신서 증설=b.xlsx@2027-06-01" "노동리·우정리=c.xlsx@2027-09-01" --name "3개 사업" -o output/복합
```

## 사용법 (명령줄)

```bash
pip install -r requirements.txt                    # PDF 변환은 LibreOffice(soffice) 필요(없으면 HWPX·XLSX만)

python3 -m cpa template templates/입력서식_템플릿.xlsx  # 빈 입력서식
python3 -m cpa run examples/예제_대죽공공폐수_입력.xlsx -o output/예제_대죽
# 수량첨부 검토(공정별 수량파일 → 입력서식 자동 작성 → 검토·성과품)
python3 -m cpa qty --work 처리시설공사 수량/토공.xlsx 수량/구조물공.xlsx --work 관공사 수량/관로공.xlsx \
    --name "○○사업" --start 2027-03-01 --end 2028-10-31 --cost 9800 --loc "충청남도 서산시" -o output/○○사업
python3 -m cpa stations 경기도                       # 관측지점 검색
python3 -m cpa db 유로폼                            # 1일작업량 DB 검색
python3 -m cpa fill 입력.xlsx --items 수량.csv --acts 공정.csv --cases 사례.csv
```

### 검토엑셀 재현 검증
```bash
python3 tools/verify_excel.py examples/엑셀재현/검토엑셀_원본.xlsx output/엑셀재현_검증
```
기존 검토엑셀(①~⑦ 시트 구조)을 입력서식으로 변환(`tools/excel_to_input.py`)하여 사업별·통합 산정 후 엑셀과 비교표·검증보고서를 작성합니다.

### 입력서식 (`templates/입력서식_템플릿.xlsx`)
`1_공사개요` · `2_비작업조건` · `3_수량` · `4_공정` · `5_유사사례` (노란 셀 입력)

선행공정 표기: `C10`(완료 후) · `C10:FS+5` · `C10:SS50%`(선행 50% 진행 후) · `C10:SS+10` · `C10:FF+0`

### 성과품 (`output/<사업명>/`)
| 파일 | 내용 |
|---|---|
| `01_공사기간산정보고서.hwpx/.pdf` | 제1장 사업개요 / 제2장 공사기간 산정·적정성 검토·결정 / 제3장 예정공정표 |
| `02_보고서부록.xlsx/.pdf` | 부록1~11: 공휴일, 기상조건, 관측지점 원자료·월별 산정표, 1일작업량 적용, 작업일수 세부, CPM 계산표, 공기조정 이력, 적정성 산정근거, 동절기, 시공조건, 작업경과 |

## 유의사항
- 보정계수 기본값(현장여건 0.85~1.0 등)과 기상프로필 구성은 가이드라인에 정량값이 없어 **검토자 판단 기본값**입니다. 입력서식에서 수정하십시오.
- 건설사업관리기간표([별표2])·환경공단 기준은 샘플보고서 수록값이며, 고시 개정 시 `cpa/refdata.py`를 갱신하십시오.
- 예제 입력의 일부 1일작업량은 샘플보고서의 작업일수에서 역산한 값(비고에 표시)입니다.
- 미세먼지(비상저감조치) 월별 발령일수는 부록3에 없으므로 에어코리아 권역별 발령내역을 직접 입력합니다.
